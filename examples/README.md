# Examples

This directory will hold small fixture projects and example evaluation outputs.

Examples should be designed to test evaluator behavior, not to become real projects.

Initial planned cases:

- Personal project with intentional creator-specific assumptions.
- Shared project with moderate onboarding friction.
- Adoptable project with missing first-use documentation.
- Functionally complete project blocked by governance.
- Project with insufficient verification evidence.
- Mixed-surface project with more than one applicable delivery standard.
